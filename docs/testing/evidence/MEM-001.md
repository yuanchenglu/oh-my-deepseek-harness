## 1. Problem

Memory 写入不幂等（CR-P1-004）：同一记忆内容同一来源重复导入会写入多行，
导致重复/错误记忆。storage 层 `memories` 表无内容唯一键，`insert_memory`
总是 INSERT 新行。

## 2. Implementation

在 `src/harness_server/storage.py` 实现去重不变量：

- `memories` 表新增 `content_hash` 列（sha256(content|source)）+ 唯一索引
  `idx_memories_content_source`，同 content + 同 source 只保留一条（TC-MEM-003）。
- `insert_memory` / `bulk_insert_memories` 改用 `INSERT OR IGNORE` 幂等写入，
  重复时跳过、返回 0。
- 兼容旧库迁移：ALTER 补列 → 清理存量重复（同 content+source 保留 id 最大）→
  回填 hash → 建唯一索引。处理了 CR-P1-004 已在库里产生的脏数据。
- `MemoryEntry` 增加 `source` 字段；`_row_to_memory` 回填 source，保留
  数据来源（FR-MEMORY-007）。

`src/harness_server/models.py` 给 `MemoryEntry` 加 `source` 字段。
