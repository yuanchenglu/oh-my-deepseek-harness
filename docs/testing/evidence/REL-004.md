## 1. 可证伪假设

基线中当前 Runtime 通过 `_TOOL_HANDLERS` 注册 9 个 Tool，而 Beta 规格与测试分母要求 10 个。若目标名称继续在 Runtime、Manifest、测试和文档中独立维护，名称与数量会漂移。通过建立一个目标常量，并用显式 pending 集合派生当前 Runtime，可以在不注册空实现的前提下冻结 Beta 分母。

## 2. 唯一机器可读目标源

```text
plugins/deepseek-harness/tools.py::TARGET_PUBLIC_TOOL_NAMES
```

目标共 10 个：

```text
checkpoint_create
checkpoint_review
memory_filter
memory_query
memory_store
memory_tag
plan_cascade
plan_create
plan_status
plan_update_step
```

排序仅用于证据展示；领域顺序保留在目标常量中。

## 3. 当前 Runtime 派生规则

```text
PENDING_PUBLIC_TOOL_NAMES = {memory_store}
RUNTIME_PUBLIC_TOOL_NAMES = TARGET_PUBLIC_TOOL_NAMES - PENDING_PUBLIC_TOOL_NAMES
```

结果：

- 目标：10；
- pending：1；
- 当前 Runtime：9；
- `memory_store` Handler：不存在；
- `memory_store` Schema：不存在；
- `ctx.register_tool(memory_store)`：不存在。

## 4. Registry 不变量

以下 Key Set 必须完全等于 `RUNTIME_PUBLIC_TOOL_NAMES`：

- `_TOOL_HANDLERS`；
- `_TOOL_SCHEMAS`；
- `_TOOL_DESCRIPTIONS`。

`register_all_tools()` 在注册前执行 registry consistency validation，并按派生 Runtime 清单注册。
