## 1. Runtime 结构

公开入口：

- `harness_server.server.create_app()`：可注入 RuntimeConfig、Storage 或 Storage Factory；
- `python -m harness_server.server`：通过 Uvicorn factory mode 启动；
- `harness_server.config.RuntimeConfig`：唯一环境变量契约。

原有 Plan/Memory/Checkpoint 业务路由原样保存在内部 `harness_server.app`。公开 Factory 只复制 `/plan/**`、`/memory/**`、`/checkpoint/**`，不复制旧 `/health`。

## 2. 单一环境变量契约

```text
HARNESS_HOST
HARNESS_PORT
HARNESS_DB_PATH
HARNESS_IMPORT_MEMORIES
HARNESS_MEMORIES_DIR
```

规则：

- 默认 Host：`127.0.0.1`；
- 仅接受 IPv4/IPv6 loopback 或 `localhost`；
- Port 必须为 1–65535；
- Memory import 默认关闭；
- DB/Memory 路径在 RuntimeConfig 创建时展开；
- 旧 `HARNESS_SERVER_PORT` 与 `HARNESS_SERVER_URL` 在 active source/tests 中为 0 references。

远程监听、认证与 TLS 不属于 RUN-001。

## 3. Import 副作用边界

`import harness_server.server`：

- 不创建 SQLite；
- 不创建 `~/.hermes`；
- 不扫描 Hermes Memory；
- 不启动进程；
- 不加载内部业务路由模块。

Storage 创建发生在 `create_app()`；可选 Memory import 只发生在 FastAPI lifespan，且需要 `HARNESS_IMPORT_MEMORIES=true`。

内部历史路由首次加载时：

- Storage constructor 被 Factory 注入；
- HOME/USERPROFILE 暂时指向空临时目录；
- 不读取真实用户 Memory；
- 加载后所有 endpoint globals 指向 Factory 的 Storage。

## 4. 探针语义

| Endpoint | 含义 | DB 依赖 | 响应安全 |
|---|---|---|---|
| `/health` | 进程 liveness | 无 | 仅 status/service |
| `/ready` | SQLite readiness | 有 | 成功 `ready`；失败固定 `storage_unavailable` |
| `/version` | Runtime/API 版本 | 无 | distribution version + api_version |

禁止返回 DB path、HOME、Memory path、异常文本或环境值。
