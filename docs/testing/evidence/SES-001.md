## 6. Architecture boundaries

- Single canonical `SessionPolicyStore` (thread-safe singleton, RLock).
- `gate.py::on_pre_llm_call` writes constraints to the store by `session_id`.
- `assessor.py::_check_constraint_violation` reads from the store by `session_id`.
- Cancelled constraints marked `active=False` (not physically deleted) for audit trail.
- CTX-004 per-Session compressor state remains Context-internal.
- No second Context runtime, no second production Session loop.
- `_current_hard_constraints` global retained as compatibility layer for legacy tests; actual storage migrated to `SessionPolicyStore`.
