## 2. Hermes 宿主边界

Hermes Agent v0.19.0 是完整产品宿主，要求 Python `>=3.11,<3.14`；项目 package/core 支持 Python 3.10–3.12。因此 Hermes 不作为 base 或 context extra 的无条件 Python dependency。

Context 包结果：

- 真实 `DeepSeekContextEngine` 实现保持在 `src/deepseek_context/_engine.py`，领域逻辑未改；
- 无 Hermes 的 clean environment 可以 import package、读取 metadata 和验证 OpenAI extra；
- `HERMES_CONTEXT_AVAILABLE` 明确表示真实宿主是否存在；
- `deepseek_context.plugin.register(ctx)` 在缺少 Hermes 时明确抛出 RuntimeError；
- 真实 discovery、selection、lifecycle 和 Tool E2E 仍由 `COMPAT-001` 负责。

这不是无 Hermes 运行 Context Engine 的承诺，也不伪造兼容性。
