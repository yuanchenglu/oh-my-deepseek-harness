## 1. 交付范围

INS-001 建立唯一 installed-distribution 安装路径：

```text
pip-installed wheel
  → deepseek-harness install [--dry-run]
  → deepseek_harness.installer
  → deploy packaged Hermes thin adapters
  → initialize private product data/config
  → canonical Supervisor start/reuse
  → health/ready validation
```

交付包括：

- `deepseek-harness install --dry-run`：完整报告、零持久写入；
- `deepseek-harness install`：从 wheel 外部环境部署 Plugin/Context 薄入口、配置和数据目录；
- CLI 不调用 pip，不管理 Python distribution；
- `scripts/install.sh` 仅作为 canonical CLI 的薄包装，不维护第二套安装逻辑；
- 同版本重复安装复用相同 managed files 与同一个 Server PID；
- 默认关闭 Summary 外发、Tool 参数外发、启动 Memory 导入和内容日志；
- managed 目录 `0700`、文件 `0600`；
- 用户已有冲突文件或 symlink 被保留并 fail-closed；
- 事务失败可回滚本次创建内容；回滚不完整时保留 ownership/deployment 证据并返回退出码 6。
