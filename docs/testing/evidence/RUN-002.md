## 1. 交付范围

RUN-002 建立一个由 CLI 与 Hermes Tool 共用的本地 Harness Server Supervisor：

- `deepseek-harness server start/status/stop/restart`；
- 跨进程排他锁，两个独立 CLI 并发 `start` 只产生一个 Server；
- 原子 JSON state；
- PID + 随机 instance ID + OS process-start token + 精确 argv ownership；
- `/health`、`/ready`、`/version` 与 port 验证；
- foreign、stale、corrupt state 的 fail-closed 处理；
- unmanaged port conflict 明确失败；
- SIGTERM 超时后、SIGKILL 前再次验证 ownership；
- stdout/stderr 写入用户可访问日志；
- data/runtime/log 目录 `0700`，state/lock/log 文件 `0600`；
- Tool 自动启动与 CLI 统一调用同一个 `Supervisor`；
- `deepseek-harness` console script 进入 wheel 契约。

## 2. 严格 Code Review 发现与修复

| 严重度 | 发现 | 修复与验证 |
|---|---|---|
| P0 | 仅依赖命令行子串不足以抵御 PID reuse 或伪造 marker | state schema v2 保存 process-start token；ownership 同时要求 PID 存活、start token 一致、精确 argv 序列及随机 instance ID |
| P0 | failed-start cleanup 吞掉终止失败并删除 state，可能留下孤儿进程 | 精确 `Popen` 子句柄优先清理；identity 变化时保留 state 并拒绝发送信号 |

| P1 | 子进程 `Popen` 后到 `exec` 完成前可能被瞬时误判 foreign | 仅在 PID/start-token 未变化时容忍 250ms exec 过渡；超时仍判 foreign |
| P1 | Tool 路径的 corrupt/config/permission 异常可能逃逸 handler | Supervisor 启动与 HTTP 调用置于同一错误边界，保持 Tool 返回字符串错误契约 |
| P1 | 外部 wheel 探针仍绑定旧 `_SERVER_MODULE` 私有常量 | 正式迁移为 Supervisor/CLI/RuntimePaths/console-script 制品契约，保留外部安装与导入验证 |
| P2 | `EntryPoints[0]` 在 Python 3.12 不兼容 | 使用迭代访问，Python 3.10–3.12 均验证通过 |
| P2 | 一个 Tool 单测会尝试使用默认真实 HOME 启动 Server | 改为完全隔离的 monkeypatch + `tmp_path`，不访问真实 HOME/DB/网络 |
