## 1. 目标

实现本地 Harness Server 的单进程监管：

- `start`：探测现有进程，避免双启，等待 readiness；
- `status`：验证 PID、instance ownership、port、health、ready、version；
- `stop`：只停止可证明归属的进程，且幂等；
- `restart`：安全 stop 后创建新的 instance；
- stdout/stderr 写入用户可访问日志；
- runtime state、lock 和 log 使用私有权限。

## 3. 安全边界

- 默认数据根：`~/.hermes/oh-my-deepseek-harness`；
- data/runtime/log 目录目标权限：`0700`；
- state/lock/log 文件目标权限：`0600`；
- state 原子写入；
- ownership 使用 PID + 随机 instance ID + child command marker；
- status 还验证 port、`/health`、`/ready`、`/version`；
- PID 存活但 ownership 不匹配时返回 `foreign`；
- `stop` 对 foreign PID 必须拒绝发送任何信号；
- 启动时端口已被 unmanaged process 占用必须失败；
- 所有测试使用临时 HOME、数据根、DB 和端口。
