## 1. 交付范围

INS-003 建立唯一 destructive lifecycle implementation：

```text
deepseek-harness upgrade [--dry-run]
deepseek-harness recover
deepseek-harness uninstall [--purge-data --confirm]
  → deepseek_harness.lifecycle
  → canonical installer + Supervisor
```

### Upgrade

- dry-run 报告 Config、DB、JSONL events、进程和备份影响，零写入；
- 同版本 upgrade 复用 installed transaction，无备份增长；
- 版本变化时备份 managed adapters、config、SQLite DB 和 events JSONL；
- 私有 transaction marker 记录 phase、backup、prior running state 和版本；
- replacement 后执行 canonical installer 与 Server ready 验证；
- 普通失败自动恢复 previous deployment/config/DB/events/process state；
- 进程级中断保留 marker 和 backup，`recover` 可恢复并重试。

### Uninstall / Purge

- ordinary uninstall 停止 verified managed Server，移除 packaged adapters 与 runtime state；
- 保留 Python distribution、config、DB、events、logs、backups 和外部 DB；
- 只输出精确手工命令 `python -m pip uninstall oh-my-deepseek-harness`，绝不调用 pip；
- purge 缺 `--confirm` 返回 2 且零变化；
- confirmed purge 只删除 canonical `~/.hermes/oh-my-deepseek-harness` owned root；
- `.hermes`/product root/descendant symlink、非 canonical root、unknown top-level path 均 fail-closed。
