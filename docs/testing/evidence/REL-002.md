## 1. 可证伪假设

基线存在三类冲突：

1. `CONTRIBUTING.md` 要求从 `master` 创建普通分支并把 PR 合回 `master`；
2. 发布计划要求 `develop` 是唯一集成和目标默认分支，`master` 仅保存 Release Gate 通过的基线；
3. 仓库没有 PR 模板，且实际默认分支仍为 `master`。

核对后假设成立。

- `docs/contributing/BRANCH_POLICY.md`：定义 Branch Role、正常集成流、Release Flow、Ruleset 要求、紧急恢复和验证清单。
- `docs/README.md`：索引治理文档并明确外部设置未完成。

本部分不修改业务代码、package metadata、Plugin manifest、installer、workflow 或 Runtime 行为。
