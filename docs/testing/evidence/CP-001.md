## 1. Problem

Checkpoint 无归属校验、无唯一编号、无 completed IDs 校验，导致归属错误、
并发编号重复、非法快照。

## 2. Implementation

- `checkpoints` 表加唯一索引 `(plan_id, checkpoint_number)` + 旧重复清理迁移
  （TC-CP-004 并发编号唯一）。
- `insert_checkpoint` 校验 Plan 存在，不存在抛 ValueError（TC-CP-002）。
- `CreateCheckpointRequest` 加 `field_validator`：completed_step_ids 必须 ⊆
  plan_steps 的 step_id（TC-CP-003）。
- `_get_next_checkpoint_number` / `insert_checkpoint` 加线程锁，编号生成+插入
  原子（TC-CP-004）。
- Review 为确定性纯函数（无写库），天然幂等（TC-CP-005）。
- Chain 按 checkpoint_number 升序（get_checkpoint_chain 已有 ORDER BY，TC-CP-006）。
